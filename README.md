# 🌸 Dự Án Thiệp 20/10 Handmade Vintage & Canva Edition Dành Cho Người Yêu 💕

Trang web quà tặng 20/10 được thiết kế kết hợp hoàn hảo giữa **Chiếc thiệp Handmade Vintage 3 khúc (Scrapbook Tri-fold Card)** từ TikTok Shop và **Mẫu trang web nghệ thuật cao cấp (Canva The Serenia)** với tông màu đỏ rượu vang Burgundy sang trọng.

---

## ✨ 4 Màn Trải Nghiệm Cảm Xúc (Interactive Flow)

1. **Màn 1 - The Teaser (Bìa thiệp vintage gập)**:
   - Dòng chữ: `Dear Em Yêu 💕` • `I got you something special.`
   - Lời trêu đùa: `Don’t open it yet. Let me see your reaction first! 😉`
   - Nút mở thiệp kích hoạt nhạc nền lãng mạn và pháo hoa giấy confetti.

2. **Màn 2 - Thiệp Handmade Vintage 3 khúc (Scrapbook Tri-fold)**:
   - **Khúc trên**: Phong bì bưu điện *London Air Mail* (chạm vào mở ra lá thư bí mật) + Tờ lịch handmade tháng 10 với ngày **20** được đánh dấu bằng trái tim đỏ nổi bật `❤️`.
   - **Khúc giữa**: Bức thư viết tay nét mực bút máy chân thành, chữ ký đỏ.
   - **Khúc dưới**: Album ảnh **Waterfall Card** lật từng tấm ảnh kỷ niệm Polaroid thật của 2 bạn (bộ ảnh photobooth tai mèo, giải Quán quân Gametopia, mũ bảo hiểm chu môi, vé máy bay Palette Air, 2 bàn tay ghép tim).

3. **Màn 3 - "Choose One" (3 Hộp Quà Bí Mật Canva Style)**:
   - 💖 **Hộp 1 - Ngàn Lời Yêu**: Bức ảnh 2 bàn tay ghép tim ở giữa, xung quanh là các câu tỏ tình uốn lượn bằng 8 thứ tiếng (`I love you`, `Aishiteru - 愛してる`, `Je t’aime`, `사랑해`, `Wǒ ài nǐ`, `Te amo`...).
   - 🎵 **Hộp 2 - Our Memories & Favourite Song**: Máy đĩa than cổ điển quay êm ái cùng album ảnh kỷ niệm dán băng dính washi tape (ảnh chụp photobooth vé máy bay, giải Gametopia, nàng game thủ chơi LMHT, bữa ăn ấm áp, đón em ở hầm xe...).
   - 📜 **Hộp 3 - Tâm Thư Dài 20/10**: Bức tâm thư xúc động viết trên giấy da cổ ngả vàng dành riêng cho cô gái của bạn.

4. **Màn 4 - Câu Hỏi Tương Tác Dễ Thương**:
   - Nút "Hông thèm đâu": Tự động né tránh chuột/ngón tay khi chạm vào.
   - Nút "Dạ có": Pháo hoa rực rỡ và Popup thông điệp yêu thương ngọt ngào!

## 🚀 Cách Đưa Lên GitHub Pages Để Gửi Link Cho Người Yêu

1. **Commit & Push code lên GitHub**:
   Mở PowerShell hoặc Command Prompt trong thư mục dự án và chạy:
   ```bash
   git add .
   git commit -m "Hoàn thành thiệp 20/10 handmade vintage cho người yêu"
   git branch -M main
   git push -u origin main
   ```
2. **Kích hoạt GitHub Pages**:
   - Truy cập: `https://github.com/XuanKio/20-10-cho-ng-i-y-u/settings/pages`
   - Mục **Branch**: Chọn `main` ➔ Thư mục `/ (root)` ➔ Bấm **Save**.
3. **Gửi link cho người yêu**:
   - Sau 1-2 phút, truy cập link:
     `https://xuankio.github.io/20-10-cho-ng-i-y-u/`
   - Copy link gửi qua Messenger/Zalo để bạn gái mở xem ngay trên điện thoại!
